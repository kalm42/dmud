# SceneDivider

The drawn `gilt` flourish between one scene and the next. Purely decorative (`aria-hidden`); the following `SceneHeading` carries the structure.

**Consumer provides:** nothing — place it between the last turn of a scene and the next `SceneHeading`.

- One per scene change, never between ordinary turns.
- Centred on the story column with `space-7` above and `space-6` below.
