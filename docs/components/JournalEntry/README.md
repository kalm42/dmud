# JournalEntry

A text-first row in the Journal that restates known facts and recorded commitments, separated by `rule`.

**Consumer provides:** `title`, a written `status` ("Known", "Commitment", "Kept"), the content as `children`, and an optional `source`.

- Status is a word, never a color chip alone.
- Never expose hidden motives or state, and never recommend what to do next.
- Empty and failed-read states must not invent concerns or hints.
